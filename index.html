02 · ARCHITECTURE

Agent 会研究，但不能自己成为事实

系统像一家有内控的研究机构：Research Agent 是研究员，Signal OS 是合规与账房，Cockpit 是操作台，人负责关键签字。

入口CLI · Cockpit · scheduler
→
唯一应用端口相同合同与写入路径
→
权威分离Agent 提案 · Core 校验 · 人签署

商品候选 ≠ 权威观测

Provider/Agent 内部 Proposal 必须通过确定性映射，不能演变成第七个顶层契约。

原文声称 ≠ 公司净敞口

材料说“利好”只能作为 source claim；公司级证据不足时仍显示 unknown。

Agent 回答 ≠ 事实升级

Ask 结果可保存为人工复核草稿，但不能自动关闭 gap、晋级或推进 checkpoint。

切片通过 ≠ 产品完成

每次验收只证明自己的范围，生产自动运行仍需独立耐久性证明。

03 · END-TO-END JOURNEY

一条真实线索如何走到人工决策

  1. 成功摄入文本Signal OS 消费 source identity，不改变 raw/wiki 原有写入。
  2. L0 商品候选身份默认 unresolved，保留原词与证据位置。
  3. 人工确认当前提及只确认本篇，不自动创建全局 AliasRule。
  4. 结构化报价 Proposal经过 LicenseGate；认证材料与原始会员页不进入公开数据。
  5. 确认 Quote Series产品、规格、市场、地区、币种、单位、税运口径必须一致。
  6. Observation 与 Event历史不足时 1/7/30 日变化保持 unknown，不拼接不同序列。
  7. HypothesisV2 与 Alert公司证据不足就生成 evidence gap，而非硬判受益。
  8. Ask / Confirm / Wait / Ignore先 preview，再对精确 revision/digest 做人工 commit。
  9. Ask 研究交接只读 Agent 返回 Proposal 与检索引用，第二次人工操作才保存草稿。
  10. Checkpoint 与 replay完整发布才推进；同 source 重放不重复，失败进入 quarantine。

04 · WHAT CHANGED

Stage 2 的六组核心变化

T37–T41

统一入口与 Cockpit

CLI、Desktop 和未来 scheduler 共享一根 typed application port；Cockpit 加入九类只读状态、手动运行、verify 与 quarantine recovery。

T42A / C

精确人工签署

每次写入先生成 DecisionEvent preview，commit 时在 single-writer 锁内重算；任何漂移 fail closed。

T42B

Quote Series 可确认、可复用

只有完整口径一致才比较价格；没有同序列历史就明确 unknown。

T43

原文观点与公司权威分离

Cockpit 同屏展示“原文可能正向”与“净敞口 unknown”，并把缺口路由成 Ask。

T45–T49

自动化就绪

加入 bounded run-once、retry、outbox 恢复、可观察性和可逆调度管理，但生产服务不因代码存在而自动启用。

ASK HANDOFF

研究结果不再丢失

Ask 工作项、只读 Agent、显式草稿保存、重启恢复、应用内复核和精确检索引用形成连续旅程。

06 · HONEST LIMITS

公开页面刻意不展示什么

绝不公开

本地绝对路径、Cookie/token/password、Provider 原始响应、会员页、原文材料、未提交文件名、研究草稿正文。

只公开统计

分支短哈希、ahead/behind、变更文件数量、切片标题、测试数量与验收布尔状态。

不会自动宣称完成

任何能力只有在受控切片留下测试、构建或浏览器验收证据后，才进入动态进度；没有证据就保持未确认。

准确说法：这个站点报告“哪些纵向切片已经留下可验证证据”，而不是根据代码数量或 Agent 的自我判断宣布整个产品完成。

07 · REQUIRED QUIZ

你必须通过的测验

通过线：10 / 12。提交后显示每题解释。

1. 顶层产品架构共有几个稳定边界？

Research Agent 属于 InvestmentSkill 内部能力，不是第七个边界。

2. commodity-price-candidate 是什么？

它必须经过确定性校验和映射。

3. 为什么决策先 preview 再 commit？

确认的是具体版本，不是可能变化的模糊标题。

4. Quote Series 只有一天数据，1/7/30 日涨幅是什么？

系统不混算不同序列，也不编造历史。

5. 原文说“某公司受益”，能立刻标正向净敞口吗？

原料、产量、转嫁和利润敏感度仍需公司级证据。

6. Ask Agent 完成后会自动关闭 evidence gap 吗？

草稿是研究交接，不是事实升级。

7. 哪项属于人类权威？

自动化不能代替人签署关键 DecisionEvent。

8. checkpoint 何时推进？

半套状态不能推进 checkpoint。

9. scheduler 的准确状态是什么？

自动化就绪不等于生产已启用。

10. Ask Proposal 如何保存？

草稿固定 refs 与 gap，但不改变 Signal OS 权威。

11. 公开进度站点读取什么？

GitHub Pages 不连接本地机器，只托管已发布快照。

12. 动态站点多久更新？

同一天重复发布只替换当天点位。
